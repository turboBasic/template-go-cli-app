# ADR 0001 — Project strategy

## Decision

Use a reusable GitHub template for Go CLI applications. Each instantiation produces an independent project; the template is not a shared runtime framework.

## Context

Accepted scope is a reusable starting point for modern Go CLI projects. The available final register does not preserve additional ADR-001 rationale.
