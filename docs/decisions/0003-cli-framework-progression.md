# ADR 0003 — CLI framework progression

## Decision

Use Cobra for the Stage 1 command hierarchy. Add Fang in Stage 2 for richer help and error presentation.

## Context

The accepted stage plan names both frameworks and their sequence. The final register does not preserve additional rationale.

## Options

Not saved.

## Consequences

- This decision is part of the frozen Architecture Specification v1.0 baseline.
- Implementations must preserve the stated contract and the stage boundary.
- Any scope change requires an explicit ADR amendment under ADR-0020.
