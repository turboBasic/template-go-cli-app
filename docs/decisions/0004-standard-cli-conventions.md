# ADR 0004 — Standard CLI conventions

## Decision

Provide hierarchical lowercase kebab-case commands, consistent global flags, help, shell completion, version information and non-interactive-safe behavior. Keep conventions overridable.

## Context

The baseline calls for consistent command behavior while allowing generated applications to adapt conventions.
