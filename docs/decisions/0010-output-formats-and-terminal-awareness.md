# ADR 0010 — Output formats and terminal awareness

## Decision

Support text and JSON results. Keep results on stdout and diagnostics/progress on stderr. Detect terminal capabilities, provide color controls and degrade safely under redirection.

## Context

The accepted output contract requires machine-readable output and stream separation. YAML and CSV are explicitly excluded.
