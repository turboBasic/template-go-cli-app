# ADR 0014 — Versioning and release automation

## Decision

Embed build/version metadata. Use semantic Git tags and GoReleaser with GitHub Actions to publish release archives, checksums and changelogs for Linux/macOS AMD64/ARM64.

## Context

The accepted register selects semantic versions and GoReleaser in Stage 2. Stage 2 release behavior is unchanged by ADR-019.
