# ADR 0015 — Template setup and developer tooling

## Decision

Provide a GitHub template, initialization tasks managed by mise, Prek hooks and CI aligned with local quality commands. Initialization updates project names, Go module identity and configuration identifiers while retaining a runnable project.

## Context

These are the accepted template and developer-experience deliverables. Hooks should stay fast; full integration, race and release checks run separately.

## Options

Not saved.

## Consequences

- This decision is part of the frozen Architecture Specification v1.0 baseline.
- Implementations must preserve the stated contract and the stage boundary.
- Any scope change requires an explicit ADR amendment under ADR-0020.
