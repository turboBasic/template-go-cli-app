# ADR 0016 — Reference application

## Decision

Include a simulated infrastructure CLI using local fixtures and no external credentials. Demonstrate representative `resource list`, `resource status` and `resource apply` flows through the same application use cases.

## Context

The accepted register selects a simulated infrastructure reference application; later stages reuse the same use cases to demonstrate presentation and progress.
